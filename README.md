## Tech

- **A-Frame 1.6** — Mozilla WebXR framework
- **GitHub Pages** — Free hosting
- **Gemini Pro Image** — 360° environment generation
- **Noto Sans Bengali** — Full Bengali/Bangla support

## Usage

1. Open `https://suhreed.github.io/noshtri-vr/` in any browser
2. For VR: Open on Meta Quest browser for immersive experience
3. Gaze-click (0.6s hold) on colored hotspots for info
